# Задание 6.3

Доработать решение задачи 2.3 (калькулятор) так, чтобы
функции загружались из динамических библиотек. В одной библиотеке
находится одна функция. При запуске программы считывается каталог с
библиотеками и загружаются найденные функции.

* Каждая операция лежит в своей библиотеке `plugins/lib<имя>.so`.
* Библиотека экспортирует один объект `operation` (тип `Operation` из `operation.h`):
  символ операции, название и указатель на функцию.
* При запуске каталог читается (`scandir`), библиотеки подгружаются через
  `dlopen`/`dlsym`, при выходе выгружаются (`dlclose`).

## Сборка проекта
```bash
make
```

## Очистка результатов сборки
```bash
make clean
```

## Запуск
```bash
./calc              # операции из каталога plugins
./calc <каталог>    # операции из указанного каталога
```

## Запуск тестов
```bash
./test.sh
```

## Добавление новой операции

Создать `plugins/<имя>.c` с объектом `const Operation operation = {...};`
и добавить `plugins/lib<имя>.so` в список `PLUGINS` в Makefile
(либо просто положить готовую `.so` в каталог)
