# Задание 6.1

Доработать решение задачи 4.1 (список контактов) так, чтобы
структуры и функции по работе с двухсвязным упорядоченным списком
находились в статической библиотеке.

* Сборка создаёт статическую библиотеку `lib/libcontacts.a` (двухсвязный
упорядоченный список) и линкует с ней программу `phonebook`.

## Сборка проекта
```bash
make
```

## Очистка результатов сборки
```bash
make clean
```

## Запуск
```bash
./phonebook
```

## Запуск с заполнением списка контактов
```bash
./phonebook -s
# или
./phonebook -seed
```

## Запуск тестов
```bash
./test.sh
```
