# Задание 6.2

Доработать решение задачи 6.1 (список контактов) так, чтобы
структуры и функции по работе с двухсвязным упорядоченным списком
находились в динамической библиотеке.

* Сборка создаёт `lib/libcontacts.so` (двухсвязный упорядоченный список)
и линкует с ней `phonebook`. Путь к библиотеке прописан через rpath,
отдельно задавать LD_LIBRARY_PATH не нужно.

## Сборка проекта
```bash
make
```

## Очистка результатов сборки
```bash
make clean
```

## Запуск
```bash
./phonebook
```

## Запуск с заполнением списка контактов
```bash
./phonebook -s
# или
./phonebook -seed
```

## Запуск тестов
```bash
./test.sh
```
