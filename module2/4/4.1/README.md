# Задание 4.1

Доработать решение задачи 2.1 (список контактов) так, чтобы
для хранения данных использовался двухсвязный упорядоченный список.

* Вместо статического массива контактов используется кольцевой двухсвязный список в динамической памяти (`malloc`/`free`) без лимита `MAX_CONTACTS`.
* Контакты автоматически поддерживаются в отсортированном виде (по фамилии, при совпадении — по имени).
* При изменении фамилии или имени контакт пересортировывается в списке (`book_reorder`), а при выходе освобождается память (`book_clear`).

## Сборка проекта
```bash
make
```

## Очистка результатов сборки
```bash
make clean
```

## Запуск
```bash
./phonebook
```

## Запуск с заполнением списка контактов
```bash
./phonebook -s
# или
./phonebook -seed
```
