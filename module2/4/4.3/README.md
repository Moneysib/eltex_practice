# Задание 4.3

Доработать решение задачи 2.1 (список контактов) так, чтобы
для хранения данных использовалось бинарное дерево. Добавить
периодическую балансировку дерева.

* Данные хранятся в динамическом бинарном дереве поиска (`left` / `right`), упорядоченном по фамилии и имени.
* Обход (`book_print`) и доступ по индексу (`book_get` / `book_remove`) выполняются через симметричный обход (in-order), сохраняя отсортированный порядок.
* Каждые 5 (`REBALANCE_EVERY`) операций модификации (`book_add`, `book_remove`, `book_reorder`) дерево пересобирается в сбалансированный вид.
* При изменении фамилии или имени узел переставляется (`book_reorder`), а при выходе вся память дерева освобождается (`book_clear`).

## Сборка проекта
```bash
make
```

## Сборка проекта (при балансировке выводится схема дерева)
```bash
make debug
```

## Очистка результатов сборки
```bash
make clean
```
